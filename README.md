# tasks-api

REST API для управления списком задач (to-do).  
Хранение — in-memory (без БД). Формат обмена — только JSON.

## Требования
- Go 1.20+ (рекомендуется 1.21+)

## Запуск

```powershell
go mod tidy
go run ./cmd/server
```
## Эндпоинты

| Метод  | Путь         | Описание                   | Статус |
|-------:|--------------|----------------------------|------:|
| GET    | /tasks       | получить список задач      | 200   |
| POST   | /tasks       | создать задачу             | 201   |
| GET    | /tasks/{id}  | получить задачу по id      | 200   |
| PUT    | /tasks/{id}  | обновить задачу целиком    | 200   |
| DELETE | /tasks/{id}  | удалить задачу             | 204   |
| GET    | /health      | health-check               | 200   |

## Формат данных

### Task

```json
{
  "id": 1,
  "title": "Buy milk",
  "done": false,
  "created_at": "2026-02-01T15:44:13Z"
}
## Ошибки

Единый формат ошибок:

```json
{ "error": "сообщение" }
```
Коды статусов:

200 — успех (GET/PUT)

201 — создано (POST)

204 — удалено (DELETE, без тела)

400 — неверные данные / некорректный JSON

404 — ресурс не найден

405 — метод не поддерживается

500 — внутренняя ошибка
